# Features

What to prove about each user-visible feature of wt-dash. Prove a change by driving its new behavior and rerunning the checks of every feature it touched. Row names (`api › feature/assets`) refer to the seeded rows listed in SKILL.md.

| Feature                                                     | Behavior                                                                                                                                    | Not covered                                                                                                |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| [Projects screen](projects-screen.md)                       | Opens on the projects, most worktrees first, with each project's counts, free space and details.                                            | A scan that finds only one project (opens it directly); a scan error banner                                |
| [Worktree list and verdicts](worktree-list-and-verdicts.md) | Each project's rows sit in Safe, Review, Busy and Broken sections with their status and reason.                                             | Status unknown; unrelated history; behind main; Linux ages (backdated worktrees read as new)               |
| [Filter, search and sort](filter-search-sort.md)            | Tabs 1–6, `/` search, `s`/`S` sort and `v` grouping narrow and order the list.                                                              | Search from the projects screen; `g`/`G`, PageUp/PageDown                                                  |
| [Selection and a](selection.md)                             | Space selects one row, `a` every Safe row in view or project, Esc clears; selections carry across screens and resizes.                      | Selection surviving a rescan                                                                               |
| [Remove dialog and removal](remove-dialog.md)               | One dialog lists what goes, warns about discarded changes, toggles D and e, and removes in the background.                                  | Esc stopping a running removal; queuing a second removal; the stale-confirmation recheck; a failed removal |
| [Blocked rows](blocked-rows.md)                             | Locked, Busy and Broken rows cannot be selected or removed and say what to do; Broken offers a prune.                                       | Status unknown                                                                                             |
| [Leftover branches](leftover-branches.md)                   | Local branches without a worktree are listed as "branch" rows; unmerged ones are deleted only with D.                                       | A branch whose name matches a worktree folder; a branch with a recent agent mark                           |
| [Details i](details.md)                                     | `i` shows a row's full details, including its commits beyond main, notes, agent marks and the tool that made it; the strip shows a summary. | `R` remeasure; details of a branch row                                                                     |
| [Orphaned folders](orphaned-folders.md)                     | Worktree folders no repository knows are listed under "Orphaned folders" with their size and reason, and wt-dash deletes them itself.       | A `.claude/worktrees` orphan; the t3 folders; a folder a scanned repo still records (moved repo)           |
| [Rescan r](rescan.md)                                       | `r` rescans every repository and picks up changes made outside the app.                                                                     | A repository deleted between scans; scan errors                                                            |
| [Narrow table layout](narrow-table.md)                      | Below 100 columns the projects fill a table with a column per verdict, and Enter opens one.                                                 | Widths under 64 (short tab labels) and under 40                                                            |
| Keys overlay `?`                                            | Lists every key.                                                                                                                            | No checks yet                                                                                              |
| Quit `q` / Ctrl-C                                           | Leaves the terminal.                                                                                                                        | No checks yet                                                                                              |
| `--doctor`, `--depth`, `--wt-path`, several scan folders    | Command-line options.                                                                                                                       | No checks yet                                                                                              |
