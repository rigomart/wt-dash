wt-dash github

Clean up the worktrees your agents left behind.

Claude Code, Codex, Cursor and friends make a Git worktree for every task, each with its own node_modules. Nothing removes them. wt-dash finds them all, says which are safe to delete, and removes the ones you pick.

brew install rigomart/tap/wt-dash

macOS 13+ and Linux (glibc). Free and MIT licensed.

Every worktree gets a verdict

Safe
Its work is already in the default branch.
Review
Uncommitted, unpushed or still in use. You get told what you'd lose.
Busy
A rebase or merge is in progress. Can't be removed.
Broken
The folder is gone but Git still lists it.
Orphaned
A folder no repository knows about any more.

Three keys

  1. Run wt-dash. It scans your code folders and the agents' worktree folders.
  2. Press a to select every Safe row.
  3. Press enter, read what goes, press y. Removals run in the background.
